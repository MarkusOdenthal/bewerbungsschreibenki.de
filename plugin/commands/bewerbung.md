# /bewerbung

Erstelle eine vollständige Bewerbung aus einer Stellenanzeige.

## Anleitung

1. Prüfe ob ein Profil unter `profil/lebenslauf.md` existiert
2. Wenn kein Profil: Frage den Nutzer nach seinen Daten und erstelle das Profil
3. Bitte den Nutzer, die Stellenanzeige einzufügen (Text oder URL)
4. Analysiere die Stellenanzeige
5. Generiere Anschreiben + Lebenslauf
6. Speichere alles unter `output/{firma}_{rolle}/`
