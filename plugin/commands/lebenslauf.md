# /lebenslauf

Erstelle oder aktualisiere deinen tabellarischen Lebenslauf.

## Anleitung

1. Lies das bestehende Profil aus `profil/lebenslauf.md`
2. Wenn leer: Starte ein geführtes Interview (Berufserfahrung, Ausbildung, Skills, Sprachen)
3. Wenn vorhanden: Frage was aktualisiert werden soll
4. Speichere das aktualisierte Profil
