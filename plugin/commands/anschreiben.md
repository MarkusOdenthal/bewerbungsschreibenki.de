# /anschreiben

Generiere nur das Anschreiben (ohne Lebenslauf) für eine Stellenanzeige.

## Anleitung

1. Prüfe ob ein Profil unter `profil/lebenslauf.md` existiert
2. Bitte den Nutzer, die Stellenanzeige einzufügen
3. Analysiere die Anforderungen
4. Generiere ein DIN 5008 konformes Anschreiben
5. Speichere unter `output/{firma}_{rolle}/anschreiben.md`
