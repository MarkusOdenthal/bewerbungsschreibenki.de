# bewerbungsschreibenki.de

KI-Bewerbungs- und Lebenslauf-Generator. Claude Plugin (€39 Einmalkauf) + SEO-Website.

## Tech Stack

- **Framework:** Astro 6 (SSG)
- **Styling:** Tailwind CSS 4
- **Language:** TypeScript
- **Hosting:** Render.com (Static)
- **Analytics:** Plausible + Grafana Faro
- **Payments:** Stripe (Payment Link)
- **Linting:** Biome + Prettier (Astro files)

## Sprache

Alle Inhalte auf Deutsch. Code und Variablen auf Englisch.

## Befehle

```bash
npm run dev          # Dev-Server
npm run build        # Production Build
npm run check        # Astro + Biome + Prettier
npm run fix          # Auto-Fix Linting
npm run test:links   # Broken Link Check
```

## Projektstruktur

- `src/pages/` — Astro-Seiten (DE)
- `src/components/` — Wiederverwendbare Komponenten
- `src/content/` — MDX Blog-Inhalte
- `src/site.config.ts` — Zentrale Site-Config
- `src/navigation.ts` — Header + Footer Navigation
- `plugin/` — Das verkaufte Bewerbungs-Plugin (TODO)
